# homebrew-cantscroll

homebrew tap for [cantscroll](https://cantscroll.com) — the coding-agent-aware
phone blocker for developers.

## install

```bash
brew tap cantscroll/cantscroll
brew install cantscroll
brew services start cantscroll/cantscroll/cantscroll
```

then pair your iphone with `cantscroll pair`.
